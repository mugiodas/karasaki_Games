01大会と種目を作る

大会を作る・切り替える（大会ライブラリ）

  1. 運営用ページを開き、ホームの「大会一覧」から「新しい大会を作る」を選びます。大会ごとにデータが分かれて保存され、前の大会と混ざりません。
  2. 設定（歯車）を開くと先頭に「設定の目次」があります。目的に合わせて項目を選ぶと、その設定だけが開きます。

大会情報（目次：大会の準備 → 大会情報）

  • 大会名・日付・会場を入れます。複数日開催の場合は2日目・3日目の日付もここで登録します。

試合のルール（目次：大会の準備 → 試合のルール）

  • ポイントは「共通／リーグ用／トーナメント用」を名前付きの選択肢から選び、保存すると全種目に一括で反映されます（例：21点3ゲーム延長30点、15点3ゲーム など）。
  • 不戦勝の集計方法もここで選びます：①1ゲーム・0点（既定）②2ゲーム・30-0点（びわこ式）③勝敗のみ（倉敷式）。スコアが入っている不戦勝はどの方式でも実スコアで集計されます。

種目を作る（参加者・種目 → 種目を追加）

  • 形式は「リーグ → 上位/下位トーナメント」「リーグのみ」「トーナメントのみ」「団体戦」から選びます。
  • 1ブロックの人数、上位に進む人数、対戦順パターン（盛上＝本命対決は最終戦／即決＝初戦／標準）、3位決定戦、チャレンジトーナメント（敗者復活）の有無を設定します。
  • 種目ごとに開催日（何日目か）も選べます。
ポイント：ポイントと開催日は、大会の途中からでも結果を消さずに変更できます。人数・進出人数・パターンの変更は組合せと結果がリセットされるので、開始前に確定させてください（変更前は自動でバックアップが取られます）。

02参加者を登録する（名簿→選択）

各チームから届く名簿は、クラス別ではなくチームの全員分です。なので登録は2段階に分かれています。まず全員を「選手登録（チーム名簿）」に登録し、種目ではその中から選ぶだけにします。

手順1：名簿に全員を登録する

  1. チーム配布用Excel：「チーム配布用Excelを出力」でチーム名入りの記入用Excelを配ります（黄色いセルだけ入力でき、所属はチーム名から自動で入る様式。学年・性別の列もあります）。返ってきた全員分のファイルは、名簿カードの「Excel・CSVから取り込む（名簿へ）」で読み込みます。同じ名前＋所属の人は自動で除かれます。
  2. 貼り付け：名簿カードの貼り付け欄に、1行に1人で 名前,所属,ふりがな,学年,性別 の順に貼っても登録できます（ふりがな・学年・性別は省略可）。
  3. 名簿は検索でき、学年・性別の修正と削除も名簿カードでできます。

手順2：種目では「登録選手から選ぶ」

  1. 種目のカードで「登録選手から選ぶ」を開き、出る選手にチェックを入れます。学年・性別・名前で絞り込めます。すでにその種目に入っている人は「登録済み」と出て選べません。
  2. シングルスは「1人ずつ追加」、ダブルスは「2人でペアにして追加」を選びます。ダブルスはチェックした順に2人ずつペアになり、組めたペアが下にプレビューされます。
  3. 学年はリーグ表の丸数字（③など、選手ごと）に、性別は男女の色分け（設定でON）に使われます。2人で学年が違うペア、男女混合ペアもそのまま作れます。
注意：種目に入れた後に名簿を直しても、入れた分には反映されません。名前の直しは種目の一覧の「名前」ボタンから行ってください（同じ名前が他の種目にもあれば、まとめて変更するか聞かれます）。

種目への直接入力（飛び入り・少人数用）

  • 種目のカードには従来どおり、一括貼り付け（1行に1エントリー、ダブルスは1行＝1ペアで2人を「・」でつなぐ）と1件追加の欄もあります。
  • 登録済みの参加者は、一覧の「名前」ボタンで名前とふりがな、「学年・性別」ボタンで学年と性別を変更できます。どちらも組合せや結果はリセットされません。
  • シードは一覧の☆をタップして付けます（ブロック分けで優先配置されます）。並び替えは↑↓です。

03組合せ（ブロック分け）を作る

  1. 参加者がそろったら「組合せを作成（ブロック分け）」を押します。シード選手と同一所属が別ブロックに分かれるよう自動で配置されます。
  2. 画面下にブロックごとの顔ぶれが出るので、偏りがないか目で確認します。直したい場合はシードの付け直しや↑↓で参加者順を変えてから作り直します。
注意：組合せを作り直すと、その種目のリーグ結果は消えます。結果を入れ始めたあとは作り直さないでください（確認画面が出ます）。

当日の運営設定（目次：当日の運営 → 当日の運営）

  • コート数、開始時刻、1試合の目安時間を設定すると、タイムテーブル（時刻×コート表と、スマホ向けリスト）が自動で組まれます。流し込み（空いたコートへ順に投入）にも対応しています。

04オンライン共有をはじめる（本番方式）

結果の共有は「オンライン共有」（サーバー経由）が本番方式です。運営端末同士も観戦者も、サーバーの内容が正本になります。始め方はボタンひとつです。

大会当日の開始手順（責任者）

  1. ホーム（または設定の「オンライン共有」）で「オンライン共有をはじめる」を押します。
  2. 初めての端末ではログイン画面が出るので、責任者のメールアドレスとパスワードでログインします（次回からはログイン済みのままです）。
  3. あとは自動です。この端末の大会がサーバーに送られ、観戦リンクが発行されます。サーバーに同じ名前の大会がある場合だけ、「この端末の内容で新しく作る（おすすめ）」か「サーバーの大会を使う」かを選ぶ画面が出ます。「サーバーの大会を使う」を選ぶと、この端末の大会はサーバーの内容に置き換わります（この端末に大会の内容がある場合は、置き換える前に自動でバックアップに保存し、確認が出ます）。
  4. 観戦リンクは、ホームと設定の「オンライン共有」に表示されます。「コピー」して保護者・関係者へ配ってください。
  5. 他の運営端末でも同じように「オンライン共有をはじめる」を押し、同じアカウント（作業者アカウントでも可）でログインすれば、同じ大会につながります。1試合だけ結果を入れて、他の端末と観戦リンクに届くことを確認してください。
ポイント：大会ごとに共有の状態が端末に覚えられます。「大会一覧」で別の大会に切り替えても共有が壊れることはなく、戻ればその大会の共有が自動で再開します。

接続表示の見方

  • 画面のピルが「サーバー共有中」なら正常です。観戦側には「最終更新 HH:MM:SS」が付き、いつの内容か分かります。
  • ピルが「この端末のみ」になっている端末は、オンライン共有していません。以前に観戦者としてつながっていた端末は、起動時にその接続が解除されて「この端末のみ」になります（入力した結果は端末に残っています）。共有するには「オンライン共有をはじめる」を押して、運営者アカウントでつなぎ直してください。万が一、ピルが「観戦者として接続中」になっていたり画面の上に黄色いバーが出ていたりしたら、その端末は見るだけの接続です。結果の入力や試合の開始はできません。バーの「運営者としてつなぎ直す」を押して、運営者アカウントでつなぎ直してください（つなぎ直す前に、この端末の大会は自動でバックアップに保存されます）。
  • 通信が切れても入力は端末に溜まり、再接続したときに自動で送られます。アプリを閉じて開き直しても、共有と結果は保持されます。
  • 画面のピルに「未送信N件」と出ている間は、まだサーバーに届いていない入力があります。通信が戻ると自動で送られます（同じ入力が二重に送られることはありません）。
  • 結果の削除も含め、すべての変更はサーバーの時刻で記録され、他の端末と観戦側へそのまま伝わります。

予備の旧方式リンク

オンライン共有を使っていない大会では、従来の共有リンク（#r= を含む住所）がそのまま使えます。オンライン共有で問題が起きたときは、設定「オンライン共有」の詳細設定から「オンライン共有をやめる（この大会）」を押せば、その大会は旧方式に戻ります（入力した結果は端末に残っています）。

05試合を進める（進行ボード）

  1. 進行ボードには「試合中」と「次の試合（待機）」が並びます。待機の試合で「開始」を押すとコートを指定して試合中になります。観戦側にも「試合中・第○コート」がすぐ出ます。
  2. 試合が終わったらカードの「結果を入れる」からスコアを入れます。結果を入れると次の試合が自動で繰り上がります。
  3. 間違えて開始した場合は、カードから開始を取り消せます。
  • ホームには今日の運営状況（試合中のコート、次の試合、全体の進み具合％）がまとまって出ます。本部の確認はホームを見るのが基本です。
  • タイムテーブルでは、時刻ごとの予定と実績をリスト（スマホ）と表形式（タブレット・PC）で確認できます。

06スコアの入れ方（3通り）

方法向いている場面
カードから入力本部で結果を聞いて入れる通常運用。勝者を選んでゲームごとのスコアを入れます。スコアなしの勝敗だけでも記録できます（不戦勝など）。
審判モード（タップ入力）コートの審判がその場でタップして数える方式。ふりがなも表示されます。下書きは端末に自動保存されるので、途中で画面を閉じても続きから再開できます。
クイック入力終わった試合のスコアをまとめて速く入れる方式。紙の審判用紙からの転記に向きます。
  • 入力した結果は「元に戻す」で直前を取り消せます。古い結果の訂正・削除は、その試合のカードから行います（サーバー方式では削除も含めて全端末・観戦側へ伝わります）。
  • 審判用紙は、試合ごとの白紙シート（滋賀県高体連様式）と、記入済みの公式スコアシートを印刷できます（設定の目次「当日の運営 → 印刷・出力」）。

07棄権・訂正・当日の設定変更

当日の棄権

  • 参加者一覧の「棄権」を押すと、その選手の未消化の試合は相手の不戦勝として自動で記録されます。組み直しは不要です。「棄権を戻す」で自動記録分だけ取り消せます。
  • 棄権で試合数が減った選手向けに、公式結果に影響しない「オープン試合」（練習試合）を作ることもできます。

当日に変えてよいもの・いけないもの

変更結果への影響
ポイント設定・開催日・コート数・開始時刻結果は消えません。そのまま変えて大丈夫です
名前・ふりがな・学年・性別消えません（表示だけの変更です）
ブロック人数・進出人数・対戦順パターン・参加者の追加削除その種目の組合せと結果がリセットされます。変更前に自動バックアップが取られますが、当日は避けてください

バックアップと復元

  • 大事な変更の前には自動でスナップショットが保存されます（結果20件ごとにも自動保存）。復元は設定の目次「データ管理 → データとバックアップ」から。
  • 削除した種目は30日以内なら同じ場所から復元できます。

08リーグ順位とトーナメント

  • リーグ画面は、上に対戦表（星取表／試合リスト）、下に順位表の順で表示されます。星取表の縦軸には所属（チーム名）も出ます。
  • 順位は 勝数 → 得失ゲーム差 → 得失点差 の順で自動計算されます。完全に同点の場合は「未確定」となり、順位表の↑↓で手動で確定します（勝敗が決まらないまま勝手に順位は付きません）。
  • 同所属同士を対戦させない設定のリーグでは、該当マスは「―」になり順位計算からも除かれます。
  • リーグが終わると上位／下位トーナメントが自動で組まれます（クロスシード方式）。トーナメント表では勝者名と所属が線上に表示され、スマホの観戦画面ではカード表示も選べます。
  • チャレンジトーナメント（敗者復活）を設定した種目では、対象の敗者が自動で振り分けられます。

09観戦者への案内

  • 配るのは観戦リンクだけです。観戦側からは結果の入力や変更は一切できません（ボタン自体が表示されません）。
  • 観戦ページのホームには、大会の進み具合、試合中のコート、次の試合、優勝者がまとまって出ます。参加者一覧も見られます（所属・学年・戦績つき）。
  • 「マイ選手」：参加者一覧で☆を付けると、その選手の次の試合（時刻・コート・相手）と結果がホームの先頭に出ます。設定はその端末の中だけに保存されます。
  • 通信が切れた場合は、最後に受け取った内容が「最終更新 HH:MM:SS の内容を表示中」と明示されて残ります。再接続で自動で最新に戻ります。
案内の文例：「本日の試合結果はこちらのリンクでリアルタイムにご覧いただけます。お子さんの名前の☆を押すと、次の試合が先頭に表示されます。」

10大会が終わったら

  1. 全種目の順位が確定しているか、リーグ画面とトーナメント画面で確認します。
  2. 結果はCSVで書き出せます（設定の目次「当日の運営 → 印刷・出力」）。記録として端末にも残ります。
  3. 賞状は設定の目次「大会の準備 → 賞状」で主催者名・代表者名を設定し、印刷します。賞状は横書き（A4）のみで、受賞データを「賞状印刷」ツールへ渡して印刷する方式です。
  4. 次の大会は「大会一覧」から新規作成（または複製）します。前の大会はライブラリに残るので、いつでも切り替えて見返せます。

11トラブル対応

症状対処
観戦ページに大会が出ない・古いままページを再読み込みしてください。起動時にサーバーから最新の状態を取り直す仕様です。それでも出ない場合は、リンクが最新の観戦リンク（#srv=）か確認してください。
結果が他の端末に届かない両端末のピルが「サーバー共有中」か確認します。「この端末のみ」になっていたら、その端末で「オンライン共有をはじめる」を押してください（ログイン済みならボタンひとつでつながります。以前に観戦者としてつながっていた端末は、起動時に接続が解除されて「この端末のみ」になっています）。万が一、ピルが「観戦者として接続中」になっていたら、画面の上の黄色いバーにある「運営者としてつなぎ直す」を押して運営者アカウントでつなぎ直してください。
「未送信N件」が消えない通信が戻れば自動で送られます。しばらく待っても消えない場合は、端末の通信を確認してからアプリを開き直してください。開き直しても未送信の入力は残っています。
画面の上に赤い「保存に失敗しました」が出る端末への保存ができていません。「JSONをダウンロード」を押して今の大会データを保存し、管理者へ渡してください。そのまま入力を続けても保存されない場合があるので、まずダウンロードしてください。
ログインできないメールアドレスとパスワードを確認してください。責任者アカウントでログインできない場合は、発行した責任者へ確認を。パスワードはチャット等で送らず、直接受け渡してください。
結果を間違えて消した・変えた正しい内容を入れ直せば全端末に伝わります。大きく壊れた場合は「データとバックアップ」のスナップショットから復元できます（サーバー方式では復元内容も全端末へ送られます）。
オンライン共有が使えない（会場の通信が不安定など）設定「オンライン共有」の詳細設定にある「オンライン共有をやめる（この大会）」で旧方式（共有リンク #r=）に戻せます。入力済みの結果は端末に残るので、そのまま旧方式で共有を続けてください。
スマホで文字入力がおかしくなる検索欄などは入力のたびに画面を作り直さない作りになっています。症状が出たら、機種と画面を控えて管理者へ連絡してください。

12役割分担とアカウント

役割できること
責任者ログイン、サーバー大会の作成・紐付け、観戦リンクの発行、作業者アカウントの発行、サーバーデータの置き換え。大会に1〜2名。
作業者ログインして同じ大会に紐付け、試合の開始・結果入力・訂正。本部とコート係。
観戦者リンクを開いて見るだけ。アカウント不要。
  • 作業者アカウントは責任者が発行します（メールアドレス＋パスワード）。発行方法は責任者へお問い合わせください。作業者も「オンライン共有をはじめる」から同じ手順でつながります。
  • 初回の責任者アカウント作成は済んでいます。責任者を増やす場合も責任者が発行します。
  • 運営上の約束：パスワードは使い回さない、観戦リンクは関係者だけに配る、大会進行中に種目の人数や参加者構成を変えない。

このマニュアルの置き場所：アプリと同じサイトの /manual/ です。内容の追加・修正はいつでもできます。
